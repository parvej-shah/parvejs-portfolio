# Parvej Shah — Personal Portfolio

This is the source code for my personal portfolio, blog, and case study showcase. It highlights my work as a Full-Stack Web Developer based in Dhaka, Bangladesh.

[![Portfolio Live](https://img.shields.io/badge/Live_Site-parvejshah.vercel.app-00E676?style=for-the-badge&logo=vercel)](https://parvejshah.vercel.app)

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Server Components)
- **Database**: [PostgreSQL](https://www.postgresql.org/) (via Neon)
- **ORM**: [Prisma](https://www.prisma.io/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Deployment**: [Vercel](https://vercel.com/)
- **Content**: Markdown processing with `react-markdown`

## Local Development

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up your `.env` file with your database URL and other secrets.
4. Generate Prisma client:
   ```bash
   npx prisma generate
   ```
5. Run the development server:
   ```bash
   npm run dev
   ```

## SEO & GEO Optimized

This portfolio features advanced SEO strategies and Generative Engine Optimization (GEO) tactics:
- Full `Person`, `WebSite`, `ProfessionalService`, and `FAQPage` JSON-LD schemas.
- Auto-generated `sitemap.xml` and `llms.txt` endpoints for LLM and agentic crawlers.
- Next.js Metadata API integration for OpenGraph and Twitter cards.
